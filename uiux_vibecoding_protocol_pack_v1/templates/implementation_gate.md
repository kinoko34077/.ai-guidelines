## 利用者起点ゲート（新規UI・操作体系変更時）

`guidelines/USABILITY_POLICY.md` および `01_AGENT_PROTOCOL.md` に従い、作業に関係する範囲で次を記録する。軽微な局所変更では影響箇所だけでよい。

```txt
利用者起点ゲート:
- User Task: 誰が / 何を / どの利用場面で達成するか
- Expected Interaction: 明示要求以外に当然試す操作
- Discovery: 操作入口・割当表示・必要なⓘ等の文脈内ヘルプ
- Continuity: 保持すべき選択・入力・位置・編集状態
- Efficiency / Recovery: 反復操作の負担と取消・復元手段
- Applicability: 必須 / 条件付き / 適用外(理由) / 別要求で判断待ち
- Evidence: 初回・通常・反復・誤操作・中断復帰の必要なシナリオと証拠
- UI Acceptance: 目的達成、標準操作、発見、情報、効率、文脈、状態、回復、アクセシビリティ、実証を独立判定
```

ショートカットの **実行／操作箇所での割当表示／変更可否** は混同しない。ⓘを置くだけでヘルプの到達・理解を検証済みとしない。実装済み部品のチェックだけで欠落操作を見逃さない。

## 実装禁止条件
- 画面目的が不明。
- 主データ形式が不明。
- 危険操作の扱いが不明。
- 対象端末により根本レイアウトが変わるのに未確認。
- ユーザーがモック確認を求めているのにコードを書こうとしている。
